# Dark Mode Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make dark mode readable and consistent on the app screens (dashboard, admin, mentor, student portal), with light mode pixel-identical and public pages forced light.

**Architecture:** One TypeScript token map (`src/lib/theme/pz-tokens.ts`) is the single source of truth. A Tailwind plugin generates `:root` and `.dark` CSS variables from it, and the `pz-*` Tailwind colours become `rgb(var(--pz-x) / <alpha-value>)`, so existing class names and opacity modifiers keep working. A route-aware `ThemeProvider` forces light outside `/dashboard` and `/portal`. A rule-driven sweep then fixes hardcoded colours, and an automated contrast scan is the acceptance gate.

**Tech Stack:** Next.js App Router, Tailwind 3.4.19 (`darkMode: ["class"]`), next-themes 0.4.6, vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-02-dark-mode-design.md`

## Global Constraints

- Light mode must stay pixel-identical: never change a light-mode colour. Where a hardcoded colour needs a dark counterpart, ADD a `dark:` variant; do not swap the light value for a token whose light hex differs.
- Class names of existing `pz-*` tokens do not change (except the five "solid" renames in Task 3). Opacity modifiers like `bg-pz-primary/60` must keep working.
- Dark palette comes from Stitch project "PZ Academy Feedback System" (dark, `#10150c` surface). Roles differ from ours for secondary and tertiary; the values in Task 1 are already adapted.
- Public pages (everything outside `/dashboard` and `/portal`) are forced light.
- WCAG AA in dark on app routes: 4.5 for body text, 3 for large text (>=24px, or >=18.66px bold).
- Container pairs (`*-container` with `on-*-container`) stay the SAME in both themes so each pair stays readable by construction. This deliberately simplifies the spec table, which listed dark values for some containers. Task 1 updates the spec to match.
- Never run `next build` while a dev server is running. `npm run` is broken by the `&` in the path: use `node node_modules/typescript/bin/tsc --noEmit` and `node node_modules/vitest/vitest.mjs run`. Never edit or regenerate `src/lib/database.types.ts`. Never push.
- Stage explicit paths only. Leave untracked `docs/lead-capture-go-live-guide.md` alone.
- Commit trailer: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`

## Review Focus

1. Opacity modifiers on tokens (`bg-pz-primary/60`, `border-pz-outline-variant/40`) must still generate colour (Task 1 test asserts `<alpha-value>`).
2. Radix portals (Dialog, Select, Popover, Sonner toasts) render in `<body>`, outside the layout div. Variables must live on `html.dark`, not on a layout wrapper (Task 1 puts them on `.dark`; Task 8 opens a dialog in dark to check).
3. Native controls (select popups, date inputs, scrollbars) need `color-scheme: dark` or they stay white (Task 1 adds it and tests for it).
4. `var(--pz-outline-variant, #bfcab5)` in `globals.css` breaks once the var holds an RGB triplet. Must become `rgb(var(--pz-outline-variant))` (Task 1).
5. Text on solid brand backgrounds: bright-green button text must stay dark, hero text on constant dark green must stay light (Task 3 solid tokens + sweep rule R2, scanned in Task 8).

```ts
export function hexToTriplet(hex: string): string {
  const h = hex.replace("#", "");
  return [0, 2, 4].map((i) => parseInt(h.slice(i, i + 2), 16)).join(" ");
}

export function buildPzCss(): { root: Record<string, string>; dark: Record<string, string> } {
  const root: Record<string, string> = {};
  const dark: Record<string, string> = {};
  for (const [name, t] of Object.entries(PZ_TOKENS)) {
    root[`--pz-${name}`] = hexToTriplet(t.light);
    if (t.dark) dark[`--pz-${name}`] = hexToTriplet(t.dark);

  return { root, dark };
```

```tsx
"use client";

import { ThemeProvider as NextThemesProvider } from "next-themes";
import { usePathname } from "next/navigation";
import type { ComponentProps } from "react";

// Dark mode is supported on app screens only. Public marketing pages have no
// toggle and no dark styling, so a saved "dark" preference must not leak there.
const THEMED_PREFIXES = ["/dashboard", "/portal"];

export function isThemedPath(pathname: string | null): boolean {
  if (!pathname) return false;
  return THEMED_PREFIXES.some((p) => pathname === p || pathname.startsWith(`${p}/`));
}

export function ThemeProvider({
  children,
  ...props
}: ComponentProps<typeof NextThemesProvider>) {
  const pathname = usePathname();
  return (
    <NextThemesProvider
      attribute="class"
      defaultTheme="light"
      enableSystem={false}
      forcedTheme={isThemedPath(pathname) ? undefined : "light"}
      {...props}
    >
      {children}
    </NextThemesProvider>
  );
}
export default ThemeProvider;
```

```js
import fs from "node:fs";
import path from "node:path";
const re = /\b(bg|from|to|via|border|ring|divide|outline|fill|stroke|decoration|accent|caret|placeholder)-pz-(forest|deep|mid|pine|sage)\b/g;
let files = 0, hits = 0;
(function walk(d) {
  for (const e of fs.readdirSync(d, { withFileTypes: true })) {
    const p = path.join(d, e.name);
    if (e.isDirectory()) { if (e.name !== "node_modules") walk(p); continue; }
    if (!/\.(tsx|ts)$/.test(e.name)) continue;
    const s = fs.readFileSync(p, "utf8");
    const n = s.replace(re, (_, pre, name) => { hits++; return `${pre}-pz-solid-${name}`; });
    if (n !== s) { fs.writeFileSync(p, n); files++; }
  }
})("src");
console.log({ files, hits });
```

Keep `bg-white` only for deliberately white things: QR codes, receipt/PDF/image backdrops, print areas. Keep `bg-white/NN` overlays on photos or dark heroes. |
| R2 | `text-white` | Keep when the element or an ancestor has a constant dark or image background: `bg-pz-solid-*`, `bg-pz-on-primary-container`, `bg-pz-danger`, `bg-red-*`, a `from-pz-solid-*` gradient, or a photo overlay. If it sits on `bg-pz-primary` replace with `text-pz-on-primary` (light value `#ffffff`, same). If it sits on a surface token replace with `text-pz-on-surface`. If the background is `bg-pz-bright`/`bg-pz-primary-container` the text must be dark (`text-pz-on-primary-container`); fix it if it is white. |
| R3 | `text-gray-300…900`, `bg-gray-50/100`, `border-gray-100/200` | KEEP the light class and ADD a dark pair: `text-gray-500` → `text-gray-500 dark:text-pz-on-surface-variant`; `text-gray-700/800/900` → add `dark:text-pz-on-surface`; `text-gray-300/400` → add `dark:text-pz-outline`; `bg-gray-50/100` → add `dark:bg-pz-surface-container-low`; `border-gray-*` → add `dark:border-pz-outline-variant`. |
| R4 | arbitrary hex in a class, e.g. `bg-[#101412]`, `text-[#e0e3df]` | `dark:bg-[#101412]` → `dark:bg-pz-surface`; `dark:text-[#e0e3df]` → `dark:text-pz-on-surface`. Other hex: if it is a one-off brand/art colour keep it; if it is a surface/text colour add a `dark:` pair using the nearest token. Say which you chose in the commit body. |
| R5 | inline `style={{ color/background: "#..." }}` | If it is a data colour (chart series, status dot, brand art) keep. If it is a surface/text colour, move to a token class. |
| R6 | text sitting directly on `bg-pz-primary` or `bg-pz-secondary` | must use `text-pz-on-primary` / `text-pz-on-secondary` (these flip with the theme; a hardcoded white would be unreadable on the dark-mode light-green `primary`). |

Per file, after editing: `git diff <file>` must show ONLY class-string changes (and R5 style moves).

### Task 8: Contrast scan, fixes, and light-mode regression gate

**Files:** whatever the scan finds. Scratch files only for the scan script.

- [ ] **Step 1: Save the scan** as `scan-dark.js` in the scratchpad and run it through Playwright `browser_run_code_unsafe` with the signed-in session (user signs in first). It sets `localStorage.theme='dark'`, visits every route at 390x844, and returns, per route, text elements with contrast below AA:

```js
async (page) => {
  await page.setViewportSize({ width: 390, height: 844 });
  await page.goto('http://localhost:3100/dashboard', { waitUntil: 'networkidle' });
  await page.evaluate(() => localStorage.setItem('theme', 'dark'));
  const routes = ROUTES; // paste the route list used in the overflow audit, plus dynamic ids found via links
  const res = {};
  for (const r of routes) {
    await page.goto('http://localhost:3100' + r, { waitUntil: 'networkidle' });
    res[r] = await page.evaluate(() => {
      const parse = s => { const m = s.match(/rgba?\(([^)]+)\)/); if (!m) return null; const p = m[1].split(/[ ,\/]+/).filter(Boolean).map(Number); return { r: p[0], g: p[1], b: p[2], a: p[3] === undefined ? 1 : p[3] }; };
      const lum = c => { const f = v => { v /= 255; return v <= 0.03928 ? v / 12.92 : Math.pow((v + 0.055) / 1.055, 2.4); }; return 0.2126 * f(c.r) + 0.7152 * f(c.g) + 0.0722 * f(c.b); };
      const bgOf = e => { const layers = []; for (let p = e; p; p = p.parentElement) { const c = parse(getComputedStyle(p).backgroundColor); if (c && c.a > 0) { layers.push(c); if (c.a >= 1) break; } } let base = { r: 16, g: 21, b: 12 }; if (layers.length && layers[layers.length - 1].a >= 1) base = { r: 0, g: 0, b: 0 }; for (let i = layers.length - 1; i >= 0; i--) { const c = layers[i]; base = { r: c.r * c.a + base.r * (1 - c.a), g: c.g * c.a + base.g * (1 - c.a), b: c.b * c.a + base.b * (1 - c.a) }; } return base; };
      const bad = []; const seen = new Set(); const w = document.createTreeWalker(document.body, NodeFilter.SHOW_TEXT);
      while (w.nextNode()) { const t = w.currentNode; if (!t.textContent.trim()) continue; const e = t.parentElement; if (seen.has(e)) continue; seen.add(e); const cs = getComputedStyle(e); if (cs.visibility === 'hidden' || cs.display === 'none') continue; const rc = e.getBoundingClientRect(); if (!rc.width || !rc.height) continue; const fg = parse(cs.color); if (!fg) continue; const bg = bgOf(e); const f2 = { r: fg.r * fg.a + bg.r * (1 - fg.a), g: fg.g * fg.a + bg.g * (1 - fg.a), b: fg.b * fg.a + bg.b * (1 - fg.a) }; const L1 = lum(f2), L2 = lum(bg); const cr = (Math.max(L1, L2) + 0.05) / (Math.min(L1, L2) + 0.05); const big = parseFloat(cs.fontSize) >= 24 || (parseFloat(cs.fontSize) >= 18.66 && +cs.fontWeight >= 700); if (cr < (big ? 3 : 4.5)) bad.push(cr.toFixed(1) + ' ' + e.tagName + '.' + String(e.className).slice(0, 60) + ' "' + t.textContent.trim().slice(0, 25) + '"'); }
      return { n: bad.length, bad: bad.slice(0, 8) };
    });
  }
  return Object.fromEntries(Object.entries(res).filter(([, v]) => v.n > 0));
}
```
