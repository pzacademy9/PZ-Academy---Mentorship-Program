# Course page from a file + AI help: owner steps

Branch `course-page-import`. No database step: nothing to paste.
(Topic and webinar date need migration 0102 from the last branch to be pasted.)

## Try it on the Vercel preview

1. Admin, Courses. Click the new **Make with AI** button.
   - Three buttons: Whole course, Page only, Improve my page. Each shows its own steps.
   - Press Copy instructions on one, and paste somewhere to check it copied.
   - Press Download example file and open it.
2. **Page only:** copy those instructions into ChatGPT (or Claude, Gemini) and paste a real
   WhatsApp post about a course. Save the file it gives you.
3. Open that course in the editor. In the **Public Page** card press **Import page from a file**,
   pick the file, press Check the file.
   - You see what will change (old crossed out, new beside it) and any notes.
   - Press Fill in the boxes. Check the boxes. Nothing is saved yet.
   - Press Save Changes, then View Public Page.
4. **Improve my page:** in the same card press **Download my page as a file**. On the AI page,
   copy the Improve my page instructions, paste them in the AI chat and attach that file.
   Import the file it gives back the same way. Check that no number, price or name changed.
5. **Whole course:** Courses, Build from file, with a file that has the new parts (price, topic,
   What you'll learn, questions). The check step lists "Public page parts found". The new draft
   course has them filled in.
6. An old course file (from before) still imports exactly as before.
